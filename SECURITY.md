# Security policy

## Reporting a vulnerability

Report it privately through GitHub: on this repository, open **Security → Report a
vulnerability** (<https://github.com/alvaromr/focus-existing-tab/security/advisories/new>). Please
do not open a public issue for it.

Include the extension version (`chrome://extensions`), the browser and its version, and the steps
to reproduce.

## Supported versions

Only the latest release receives fixes.

## Scope

The extension has no host permissions, content scripts, network requests or remote code; what it
reads and why is in [PRIVACY.md](PRIVACY.md).
